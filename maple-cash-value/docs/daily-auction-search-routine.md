# 매일 경매장 2계정 검색 루틴 지시서

이 문서는 메이플 캐시샵 계산기의 경매장 가격 데이터를 계정 2개, 하루 최대 200회 안에서 갱신하기 위한 작업 지시서다. 200회는 소진 목표가 아니라 상한이다. 결론에 필요한 검색이 끝나면 남은 횟수는 다음 갱신에 보존한다.

## 목표

- 캐시샵에서 직접 살 수 있는 상품과 직업 패키지의 거래 가능 구성품만 검색한다.
- 두 계정이 같은 품목을 중복 검색하지 않도록 계정별 큐와 검색 장부를 사용한다.
- 가격 있음, 매물 없음, 후보 없음, 미확인을 구분한다.
- 뽑기 결과물과 판매 불가 품목은 검색 대상에서 제외한다.
- 최종 결론 직전에는 오래된 고가 품목부터 갱신한다.

## GPT-5.6 작업 방식

1. JSON에서 미확인 대상을 자동 산출하고 공용 구성품을 중복 제거한다.
2. 캐시샵 직접 구매 가능 여부를 먼저 판정한 뒤 검색 큐에 넣는다.
3. 자동완성 후보가 없으면 필터 검색을 누르지 않는다.
4. 검색 1회마다 계정, 검색 순번, 후보명, 결과 건수, 최저가, 상태, 시각을 기록한다.
5. 패키지 가치에 큰 모자, 얼굴장식, 상의, 무기를 먼저 처리한다.
6. 25회마다 GitHub 작업 브랜치에 중간 저장한다.
7. 두 번째 계정은 첫 번째 계정의 남은 큐만 이어받고 처음부터 다시 훑지 않는다.

## 핵심 원칙

1. 패키지명 자체가 아니라 거래 가능한 구성품명으로 검색한다.
2. 다음 항목 입력 전에는 반드시 기존 검색어를 지운다.
3. 자동완성 후보를 선택한 뒤에만 필터 검색을 누른다.
4. 후보 없음은 즉시 `no_candidate`와 수동확인으로 기록한다.
5. 후보는 있지만 결과가 0건이면 `no_listing`으로 기록한다.
6. 검색 후 다음 필터 검색까지 최소 5.25초 간격을 둔다.
7. 가격은 첫 결과 행의 메소 가격을 사용한다. 전투력증가량을 가격으로 읽지 않는다.
8. 괄호 앞 공백 차이는 alias로 기록한다.
9. 검색 제한 경고 또는 100/100 도달 시 해당 계정 검색을 즉시 종료한다.
10. no_candidate 품목은 다른 이름을 추측해 재검색하지 않고 사용자에게 확인을 요청한다.

## 검색하지 않는 항목

- 원더베리나 루나에서 나오는 개별 결과물
- 쁘띠 펫 간식처럼 캐시샵에서 직접 살 수 없는 결과물
- 스페셜 프라이스팩, 패스 등 경매장 판매 불가 상품
- 마일리지 전용 참고 품목
- 사용자가 의미 없다고 확정한 수동확인 품목
- 묶음 자체가 경매장 아이템이 아닌 `위습의 원더베리 11개`

확률형은 결과물이 아니라 상품 자체만 검색한다. 예: 위습의 원더베리, 루나 크리스탈, 스페셜 루나 크리스탈.

## 2계정 예산

### 계정 1

- 신규 핵심 구성품을 우선해 최대 100회 사용
- 시그너스, 영웅, 모험가 핵심 부위 순서
- 핵심 부위가 끝나면 부츠류를 채움
- 25, 50, 75, 100회에서 중간 저장

### 계정 2

- 계정 1에서 남은 신규 품목
- 후보가 있었던 `no_listing` 품목의 날짜 변경 재확인
- 기존 가격 중 오래되고 패키지 영향도가 큰 품목 갱신
- 남은 횟수는 오류 재확인과 최종 결론 직전 갱신용으로 보존

## 표준 검색 절차

1. 메이플 옥션 구매 탭과 캐시 필터를 확인한다.
2. 화면의 검색 횟수를 장부와 대조한다.
3. 검색어 지우기를 누른다.
4. 패키지 공통 접두어를 입력한다.
5. 자동완성에서 데이터 이름과 정확히 맞는 후보를 찾는다.
6. 후보가 없으면 필터 검색 없이 수동확인으로 넘긴다.
7. 후보를 선택하고 정확 일치 태그를 확인한다.
8. 이전 검색 후 5.25초가 지났는지 확인한다.
9. 필터 검색을 누른다.
10. 검색 횟수가 1 증가했는지 확인한다.
11. 결과 건수와 첫 행 최저가를 기록한다.
12. 다음 항목으로 이동한다.

## 저장 형식

가격 확인 성공은 `prices`에 저장한다.

```json
{
  "itemName": "데이터 기준 이름",
  "query": "경매장 정확 후보명",
  "aliases": ["공백 등이 다를 때만"],
  "listingLowestMeso": 123000000,
  "listingLowestText": "1억 2300만",
  "resultCount": 4,
  "status": "ok",
  "filter": "캐시",
  "searchAccount": 1,
  "searchIndex": 25,
  "collectedAt": "2026-07-11T20:00:00+09:00"
}
```

후보 없음은 `skipped`에 저장하고 검색 횟수를 소비하지 않는다.

```json
{
  "itemName": "모험가 캐논슈터 캐논",
  "query": "모험가 캐논슈터",
  "status": "no_candidate",
  "reason": "자동완성 정확 후보 없음; 필터 검색 미실행",
  "filter": "캐시",
  "searchAccount": 1
}
```

## 2026-07-11 계정 1 결과

- 검색 횟수: 100/100
- 필터 검색 성공: 100개
- 필터 검색 결과 0건: 0개
- 후보 없음으로 검색하지 않은 항목: 3개
- 가격이 채워진 계산 대상: 150개
- 전체 계산 대상: 164개

후보 없음 수동확인:

- 모험가 캐논슈터 슈트(남)
- 모험가 캐논슈터 캐논
- 모험가 캐논슈터 슈트(여)

기존 수동확인:

- 레지스탕스 배틀메이지 모자: 후보에는 고글만 노출
- 레지스탕스 메카닉 무기: 후보에는 건만 노출

## 계정 2 시작 큐

신규 검색 4개:

1. 모험가 캐논슈터 부츠
2. 모험가 바이퍼 부츠
3. 모험가 캡틴 부츠(남)
4. 모험가 캡틴 부츠(여)

후보가 존재했던 매물 없음 재확인 4개:

1. 데몬 슬레이어 슈트(남)
2. 레지스탕스 블래스터 헤어밴드(남)
3. 레지스탕스 와일드헌터 슈트(여)
4. 기사단장 오즈 로브(여)

위 8회 이후에는 기존 가격 중 고가 구성품과 캐시샵 직접구매 상품을 오래된 순서로 갱신한다. 후보 없음 5개는 사용자 확인 없이 재검색하지 않는다.

## 데이터 반영 위치

- 경매장 가격: `maple-cash-value/data/auction-prices.json`
- 캐시 가격과 패키지 구성: `maple-cash-value/data/items.json`
- 이 지시서: `maple-cash-value/docs/daily-auction-search-routine.md`

검색 결과는 먼저 `agent/manual-cash-value-modes` 작업 브랜치에 저장한다. 공개 `main` 반영은 사용자 승인 후 진행한다.
