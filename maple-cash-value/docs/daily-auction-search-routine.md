# 매일 경매장 2계정 검색 루틴 지시서

이 문서는 메이플 캐시 효율 계산기의 가격 데이터를 계정 2개, 계정당 하루 100회 안에서 수집하고 갱신하기 위한 작업 지시서다.

## 2026-07-12 기준 규모

- 계산기 항목: 201개
- 구성품형 항목: 181개
- 중복 제거한 자동 검색 대상: 573개
- 가격 확인 완료: 162개
- 신규 미확인 자동 검색 대상: 411개
- 수동 확인으로 분리한 대상: 8개
- 검색에서 제외하는 보너스 구성품: 60칸, 고유 이름 59개
- 두 계정 200회 기준 전체 자동 대상 1회전: 3일
- 신규 미확인 411개 최초 채우기: 3일

패키지명 자체가 아니라 거래 가능한 구성품명을 검색한다. 같은 구성품이 여러 패키지에 들어가면 한 번만 검색하고 모든 패키지에 같은 가격을 연결한다.

## 최초 3일 채우기

### 1일차: 핵심 패키지 완성

총 200개를 다음 순서로 배치한다.

1. 보스 패키지 구성품 85개
2. 노바·레프·프렌즈 월드·초월자·아니마 구성품 58개
3. 금손·은손 펫 48개
4. 금손·은손 의상 공용 구성품 중 영향 패키지가 많은 순 9개

이 날이 끝나면 신규 직업, 보스, 펫 패키지는 후보 없음이나 매물 없음 항목을 제외하고 계산 가능해야 한다.

### 2일차: 금손·은손 의상

- 금손·은손 의상 구성품 200개
- 남녀 세트에 함께 들어가는 공용 무기, 망토, 신발을 먼저 검색한다.
- 같은 영향도에서는 무기, 망토, 한벌옷, 모자, 신발 순으로 처리한다.

### 3일차: 최초 채우기 종료

- 남은 금손·은손 의상 구성품 11개
- 남은 189회는 기존 가격 중 메소 가격이 높고 갱신일이 오래된 순으로 사용한다.
- 이 시점부터 자동 검색 대상 전체를 3일 회전 큐로 운용한다.

## 계정 배분

매일 하나의 우선순위 마스터 큐를 만든다. 계정별로 카테고리를 고정하지 않는다.

- 계정 1: 마스터 큐의 홀수 순위
- 계정 2: 마스터 큐의 짝수 순위
- 각 계정은 실제 필터 검색 100회에 도달하면 종료
- 후보 없음은 검색 횟수를 쓰지 않으므로 다음 배정 항목으로 계속 이동
- 매일 큐는 최소 240개를 준비해 후보 없음이 생겨도 두 계정이 100회를 채울 수 있게 한다.
- 두 계정은 같은 큐 버전과 생성 시각을 사용한다.

홀짝 분배를 쓰면 고가 품목과 느린 패키지 품목이 두 계정에 고르게 섞이고 중복 검색도 막을 수 있다.

## 일일 200회 정규 배분

최초 채우기 이후에는 아래 비율로 매일 큐를 만든다.

1. 직접 판매·쿠폰·랜덤 상품 및 최상위 효율: 20개
2. 기존 가격 상위와 여러 패키지에 영향을 주는 공용 구성품: 60개
3. 보스·직업·펫 패키지 구성품 순환: 60개
4. 회전율이 낮은 금손·은손 의상 구성품 순환: 60개

금손·은손 의상 220개는 약 4일에 한 번 전부 갱신한다. 보스·직업·펫은 2~3일 회전, 직접 판매 상품과 상위 효율 품목은 매일 갱신한다.

## 우선순위 정렬

각 품목은 다음 순서로 정렬한다.

1. 아직 가격이 없는 판매 가능 품목
2. 현재 계산기에서 순이익 또는 메소/캐시가 높은 품목
3. 마지막 갱신일이 오래된 품목
4. 여러 패키지에 동시에 쓰이는 공용 구성품
5. 판매 종료일이 가까운 현재 캐시샵 상품
6. 회전율 주의 패키지 구성품

후보 없음은 이 자동 큐에서 제거하고 수동 확인 목록에만 둔다. 매물 없음은 정확 후보가 확인된 항목이므로 24시간 뒤 한 번만 재확인한다.

## 표준 검색 절차

1. 메이플 옥션 구매 탭과 캐시 필터를 확인한다.
2. 현재 계정과 검색 횟수를 장부와 대조한다.
3. 이전 검색어를 완전히 지운다.
4. 데이터의 정확한 구성품명 하나만 입력한다.
5. 자동완성에서 정확 후보를 확인한다.
6. 후보가 없으면 필터 검색을 누르지 않고 `no_candidate`로 기록한다.
7. 후보를 선택한 뒤 이전 필터 검색으로부터 최소 5.25초가 지났는지 확인한다.
8. 필터 검색을 누르고 검색 횟수가 1 증가했는지 확인한다.
9. 첫 결과 행의 메소 가격, 결과 건수, 시각을 기록한다.
10. 결과가 0건이면 `no_listing`으로 기록한다.
11. 25, 50, 75, 100회마다 중간 저장한다.

검색어 두 개를 이어 붙이지 않는다. 후보가 없을 때 비슷한 이름을 추측해 다시 검색하지 않는다.

## 검색하지 않는 항목

- 캐시샵에서 직접 살 수 없는 뽑기 결과물
- 쁘띠 펫 간식 같은 비판매 품목
- 스페셜 프라이스팩, 패스 등 경매장 판매 불가 상품
- 마일리지 전용 참고 품목
- 패키지의 교환 불가 보너스 구성품
- 자동완성 정확 후보가 없어 수동 확인으로 넘긴 품목

`위습의 원더베리 11개`는 묶음명을 검색하지 않는다. `위습의 원더베리` 단가를 한 번 검색하고 계산기에서 11배로 합산한다.

## 현재 수동 확인 목록

- 레지스탕스 배틀메이지 모자
- 레지스탕스 메카닉 무기
- 모험가 캐논슈터 슈트(남)
- 모험가 캐논슈터 캐논
- 모험가 캐논슈터 슈트(여)
- 데몬 슬레이어 슈트(남)
- 레지스탕스 블래스터 헤어밴드(남)
- 레지스탕스 와일드헌터 슈트(여)

이 목록은 사용자가 정확 후보를 확인해 주기 전까지 자동 재검색하지 않는다.

## 저장 형식

가격 확인 성공은 `prices`에 저장한다.

```json
{
  "itemName": "데이터 기준 이름",
  "query": "경매장 정확 후보명",
  "aliases": ["공백 등이 다를 때만"],
  "listingLowestMeso": 123000000,
  "listingLowestText": "1억 2300만",
  "resultCount": 4,
  "status": "ok",
  "filter": "캐시",
  "searchAccount": 1,
  "searchIndex": 25,
  "collectedAt": "2026-07-12T20:00:00+09:00"
}
```

후보 없음은 `skipped`에 저장하되 필터 검색을 누르지 않는다.

- 경매장 가격: `maple-cash-value/data/auction-prices.json`
- 캐시 가격과 패키지 구성: `maple-cash-value/data/items.json`
- 작업 지시서: `maple-cash-value/docs/daily-auction-search-routine.md`
